# Red-team boundary

1. **This is not the local RM(5,12)^6 proposal.** The global swap retains six
   current `K` values at `N=2^20` or `N=2^21`.  No 4,096-coordinate dimension
   or 2.323-bpw calculation transfers.

2. **Most selected counts are not RM dimensions.** Selecting a prefix of the
   RM row order is exact RM only at a complete degree boundary.  Every other
   set must be called RM-ordered truncated polar.

3. **Orientation is easy to reverse.** The normative object is the internal SC
   phase.  Under the pinned bit-reversal convention, its generator-row weight
   is `2**popcount(internal_phase)`.  Sorting external indices instead changes
   the experiment.

4. **Tie order is part of the codec.** Equal-popcount phases are ordered by
   ascending internal integer.  Unstable GPU sorts or unspecified set
   iteration are rejected.

5. **K equality must come from current flags.** A production adapter first
   calls the exact pinned BEC hook and counts zeros.  Recomputing from a copied
   or rounded capacity schedule is insufficient.

6. **Zero and random frozen values are different affine cosets.** Current
   random frozen values may erase visible polynomial structure.  A zero-coset
   result cannot be presented as current-format evidence and requires a
   separately charged selector/version.

7. **The old base CLI cannot proxy the global run.** Its command-line length
   gate stops at `2**18`; target blocks are `2**20/2**21`.  A smaller run may
   test mechanics only.

8. **Selected decisions are not physical bits.** The six selected counts can
   sum far above the emitted rate because causal arithmetic coding compresses
   them.  Conversely, `sum(K)` cannot be advertised as a saving.

9. **Ideal entropy is not physical length.** Rate is derived from the complete
   emitted packet, including termination and alignment, not selected NLL.

10. **Reusing the old stream is invalid.** The changed frozen set changes the
    SC path, reconstruction, lower-level contexts, probabilities, and
    arithmetic stream.  A production experiment must re-encode from the
    authenticated source.

11. **Decoder probabilities must be causal.** An independent decoder must
    regenerate them from frozen metadata, decoded earlier decisions, and
    completed lower levels.  Encoder-recorded frequency arrays are forbidden.

12. **Canonical replay is full-packet replay.** Re-encoding only the arithmetic
    payload is insufficient.  Header, selectors, scales, seeds, trailer and
    padding must all match byte-for-byte with no ignored suffix.

13. **The all-14 overlap receipt is not an RD result.** Its only legal use is
    evidence that the two row sets differ and overlap by a measured amount.

14. **A source manifest does not authorize payload access.** Independent
    source audit and an authenticated current-global encoder/decoder are both
    required before opening Qwen, coarse, or matched-control arrays.
