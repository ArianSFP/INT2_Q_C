No existing encoder or v8 source is edited.

The new code supplies only the missing ABI and evidence retention:

## Exact incompatibility kept explicit

The v8 `controls_phase` requires
`control_structural_geometry == source_structural_geometry`. Honest full PTQ
controls independently derive labels, profiles, selected-symbol counts and
role contribution maps, so that comparison is not valid here. The v8 function
is not patched or silently bypassed: this separately audited v9 bridge verifies
each source-derived control geometry against its own artifact and shares only
the previously frozen universal slot/role/shape/block contract.

audit, producer audit, this consumer audit, exact eight-control root, moment
replayer, descriptor builder, v8 preflight and GPU identity receipts are all
externally pinned in one run authorization.
