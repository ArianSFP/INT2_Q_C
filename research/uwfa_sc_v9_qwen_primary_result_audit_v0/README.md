# UWFA-SC v9 primary independent result audit v0

This is a separate, source-only, fail-closed audit package for the exact
nonpromoting publication emitted by
`uwfa_sc_v9_qwen_primary_gate_v0/primary_gate.py`. It contains no Qwen bytes,
completed result, control, Gaussian stream, resolved output hash, or claim
authority. Importing the verifier performs no path access, numerical import,
CUDA initialization, subprocess execution, or mutation.

The v9 primary runner deliberately cannot promote a result. A hard kill is
evidence only against the declared sparse-unifilar WFA cell. A primary
survivor merely authorizes separately frozen shuffles, coordinate diagnostics,
matched-Gaussian controls, posterior diagnostics, and another audit. It is not
a universal SwiGLU-MoE compression result.

from independently recorded facts. It must supply:

`UNRESOLVED_EXTERNAL_PINS.json` is deliberately unusable.

## Filesystem race rule

Broad ancestors such as `/workspace` are retained by device, inode, type and
name binding only. Their mtime/ctime are intentionally excluded because an
unrelated sibling can change them. The actual source-package directories,
publication directory, and all files retain full metadata and bytes. This
directly avoids the false v8 audit failure caused by creating an unrelated
`/workspace` sibling during a long replay.

Static files cannot prove historical syscall order when filesystem timestamp
granularity ties. The audit therefore requires external member pins, exact
membership, completion sealing, retained descriptors and final rebinding, and
rejects a `COMPLETE.json` that is observably older than any data member. This
limitation is explicit in the receipt.

After an external authority resolves a new pin bundle:

```text
/usr/bin/python3.12 -I -B verify_result.py \
  --authorization AUDIT_EXACT_UWFA_SC_V9_PRIMARY_NONPROMOTING_RESULT_V0 \
  --expected-audit-source-manifest-sha256 <externally-recorded-audit-manifest-sha256> \
  --external-pins /absolute/external-pins.json \
  --expected-external-pins-sha256 <independently-recorded-sha256>
```

The verifier prints one compact receipt to stdout and never modifies the
publication.
