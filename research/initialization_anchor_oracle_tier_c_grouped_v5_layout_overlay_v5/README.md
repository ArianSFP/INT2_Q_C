## Completed-result replay

Resume is immutable crash evidence, not a compute-saving mode. The journal
must be a prefix of this exact grammar:

```text
header -> stage0[000..255] -> stage0_merged
       -> overlay_state -> overlay_receipt
       -> stage1[0000..N-1] -> stage1_winners
       -> winner_firewall -> result
```

The final result event is permitted only once, last, and after the winner
firewall. Once present, the journal is write-closed. A completed result and its
journal receipt are authenticated at entry, but neither is treated as
scientific evidence. The run still:

1. loads the selection payload exactly once;
2. regenerates all 164,864 candidates in every one of 256 stage-0 shards on all
   512 frozen coordinates;
3. recomputes every full float64 `q`, exact `(metric,ordinal)` TopK2048 and the
   global new-family union;
4. recomputes and compares the old/new overlay and strict receipt;
5. rescans every exact stage-1 union batch on all 48,624 coordinates and
   independently reranks all 33 winners;
6. recomputes the winner firewall, opens validation only afterward, and
   recomputes selection details, validation details, folds, null captures and
   decision; and
7. reconstructs the complete canonical result, including the original
   pre-result journal event list, and requires exact JSON value **and byte**
   equality before returning the existing path.

Missing state cannot be repaired beneath a completed result. Surplus stage-1
batches, stale scores, old-family/noncanonical ordinals, dtype drift,
non-finite metrics, altered winners, altered validation statistics, changed
decision fields, extra result members, or noncanonical result bytes all fail
closed. Resumed header, overlay receipt, winner-firewall, journal, and result
JSON reject duplicate keys and non-finite constants.

Before each stage-0 TopK call (calibration warmup, every calibration repetition,
and production), the complete device `q` must be exactly float64 with shape
`(candidate_count,33)` and pass a device-wide finiteness reduction. TopK is not
entered after a NaN, infinity, shape drift, or dtype drift.
