# V2 independent-review repair map

| Blocking review finding | V3 source mechanism |
|---|---|
| Scientific capability self-declared its audit | `authenticate_scientific_audit_package` authenticates an exact independent audit closure, canonical capability, and separately pinned executed receipt. |
| Cross-family strings could alias identical evidence | Model checkpoint/tensor/identity/schema hashes and all source paths/byte hashes are rejected when reused across claimed families. |
| Whole-layer case could masquerade as 1x expert read | Every route is exactly one Gate/Up/Down triplet for one `(layer, expert)`, with one distinct expert-local packet and one independent decode. |
| Logical Python reads were not physical pages | Packet supply is rounded to fixed 4096-byte pages; exact pages, literal bytes, zero padding, and physical page bytes are validated. |
| Python handle proxy exposed raw/native bypasses | The decoder is zero-import WebAssembly instantiated without WASI. It receives only a copied packet buffer in private linear memory and no path/fd/native-read capability. |

The independently audited decoder must also prove the ABI, zero imports, input
immutability, canonical replay, fixed universality, and absence of Qwen tables.
These mechanisms have no runtime or result authority until their tests and the
two required external audit packages execute successfully.
