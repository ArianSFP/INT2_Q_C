# Lossy-tail v8 one-shot authorization builder

This helper creates the external authorization object required by the frozen
v8 preflight. It does not import CuPy, open model data, run the oracle, or
change the sealed v8 source package. It binds exact source/runtime PASS
artifacts, the untrusted-but-audited runtime receipt, the live interpreter and
mount snapshot, unique filesystem identities, an absent output run root, and
the fixed scientific arguments.

The output remains a one-shot operational approval, not a compression result.
Both the stdlib preflight and the scientific core independently validate every
field before source access. Successful descriptor-relative output creation
makes replay fail closed.

Run this on the target Linux host immediately before the frozen preflight,
using evidence directories disjoint from the stage, source, and output parent.
The exact command and emitted hashes belong in the eventual result receipt.
